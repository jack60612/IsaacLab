* Added :meth:`~isaaclab.envs.ManagerBasedEnv.set_step_decimation` to run a variable number of physics steps, up to ``cfg.decimation``, in each following environment step. Manager-based environments render once whenever a call crosses a render-interval boundary, so render cadence holds for any step length.
* The ROS 2 bridge ends each environment step on the physics step that reaches its next exchange deadline, so ``exchange_period_s`` exchanges at the same physics steps and integrated times as decimation one while running one environment step per exchange. Added ``Ros2Bridge.exchange_due``.
